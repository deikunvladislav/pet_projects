# 📦 WarehouseApp

Pet-проект: WPF-приложение для управления складскими запасами, разработанное с использованием паттерна **MVVM**.

## ✨ Функциональность
*   **Добавление товаров:** ввод названия, цены и количества.
*   **Редактирование:** обновление данных выбранного товара.
*   **Удаление:** удаление товара из таблицы.
*   **Сортировка** сортировка по всем полям (клик по названию столбца). Один клик - сортировка по возрастанию, два - по убыванию.
*   **Автоматический расчет:** подсчет общей стоимости (цена × количество) для каждой позиции.
*   **Валидация данных:** проверка корректности ввода цены и количества.

## 🛠️ Стек технологий
*   **Язык:** C#
*   **Платформа:** .NET 8, WPF
*   **Архитектура:** MVVM (Model-View-ViewModel)
*   **Инструменты:** Git
